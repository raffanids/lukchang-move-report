# Solution

* ผู้ส่งกรอกขนาด จำนวน และประเภทพัสดุ พร้อมถ่ายรูป ผู้ขับเห็นข้อมูลชัดตั้งแต่ต้น
* ระบุประเภทพัสดุเพื่อเลือกรถที่เหมาะสม
* ผู้ขับทุกคนต้องผ่านการตรวจสอบตัวตน (KYC) โดย Admin
* ติดตามพัสดุบนแผนที่และแชทกับผู้ขับในแอป
* AI Support Chatbot ช่วยตอบปัญหา ถ้าเกินความสามารถจะส่งต่อให้ Admin

## เทียบกับการหาคนขนของในโซเชียล

| | โพสต์หาในโซเชียล | Lukchang Move |
| --- | --- | --- |
| ความน่าเชื่อถือของผู้ขับ | ไม่รู้ตัวตน | ผ่าน KYC |
| ติดตามพัสดุ | ต้องโทรถาม | ดูบนแผนที่ได้ตลอด |
| เมื่อมีปัญหา | ต้องจัดการเอง | Chatbot + Admin ดูแล |
