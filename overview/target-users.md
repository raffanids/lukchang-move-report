# Target Users

ระบบมีผู้ใช้ 3 กลุ่ม แต่ละกลุ่มได้ประโยชน์ต่างกัน

<figure><img src="../.gitbook/assets/target-users.jpg" alt="กลุ่มผู้ใช้: ผู้ส่ง ผู้ขับ และ Admin"><figcaption><p>กลุ่มผู้ใช้: ผู้ส่ง ผู้ขับ และ Admin</p></figcaption></figure>

<table data-view="cards"><thead><tr><th></th><th></th><th></th></tr></thead><tbody>
<tr><td><h3>📦 ผู้ส่ง (Sender)</h3></td><td><mark>แอปมือถือ iOS / Android</mark></td><td>ส่งของง่ายขึ้นและมั่นใจขึ้น ระบุขนาดและประเภทพัสดุได้ชัด จองล่วงหน้าได้ และติดตามสถานะได้ตลอด</td></tr>
<tr><td><h3>🚚 ผู้ขับ (Driver)</h3></td><td><mark>แอปมือถือ iOS / Android</mark></td><td>ได้งานที่มีข้อมูลพัสดุชัดเจน แชทกับผู้ส่งได้ และดูประวัติงานกับสรุปรายได้ของตัวเอง</td></tr>
<tr><td><h3>🛡️ Admin</h3></td><td><mark>Web browser (ผ่านเครือข่ายบริษัทหรือ VPN)</mark></td><td>ตรวจสอบเอกสาร KYC ของผู้ขับ ดูภาพรวมออเดอร์และรายได้ และจัดการเคสที่ Chatbot ส่งต่อมา</td></tr>
</tbody></table>
