# User Flow

แต่ละบทบาทมีขั้นตอนการใช้งานต่างกัน เลือกแท็บเพื่อดู flow ของผู้ใช้แต่ละกลุ่ม

{% tabs %}
{% tab title="Sender" %}
<figure><img src="../.gitbook/assets/userflow-sender.jpg" alt="User Flow ของผู้ส่ง (Sender)"><figcaption><p>User Flow ของผู้ส่ง (Sender)</p></figcaption></figure>

เริ่มจากเปิดแอป ถ้ายังไม่ได้เข้าสู่ระบบ ให้เข้าสู่ระบบหรือสมัครสมาชิกก่อน แล้วทำตามขั้นตอนตามเลขในภาพ

{% stepper %}
{% step %}
### ระบุประเภทพัสดุ
เลือกว่าจะส่งของประเภทไหน
{% endstep %}
{% step %}
### ระบุขนาด จำนวนพัสดุ และจุดหมาย
กรอกรายละเอียดพัสดุที่จะส่ง
{% endstep %}
{% step %}
### เลือกขนาดรถ
เลือกรถให้เหมาะกับขนาดและน้ำหนักของพัสดุ
{% endstep %}
{% step %}
### เลือกสถานที่
ปักหมุดจุดรับและจุดส่ง
{% endstep %}
{% step %}
### ระบบแสดงราคาประเมิน
ถ้ายอมรับราคาจะไปขั้นถัดไป ถ้าไม่ยอมรับ ให้กลับไปแก้ขนาด จำนวน หรือจุดหมายใหม่
{% endstep %}
{% step %}
### ยืนยันและชำระเงิน
ถ้าชำระเงินไม่สำเร็จ ให้ลองใหม่หรือเลือกวิธีชำระเงินอื่น
{% endstep %}
{% step %}
### ระบบค้นหาคนขับ
ถ้าไม่พบคนขับภายในเวลาที่กำหนด ระบบจะแจ้งเตือนให้เลือกว่าจะค้นหาต่อหรือยกเลิก ถ้ายกเลิก ระบบจะยกเลิกคำสั่งและคืนเงิน
{% endstep %}
{% step %}
### รอคนขับมารับ
เมื่อพบคนขับแล้ว รอให้คนขับมารับพัสดุ
{% endstep %}
{% step %}
### ติดตามสถานะ Real-time
ดูตำแหน่งคนขับและแชทกับคนขับหรือ Admin ได้ ถ้าต้องการยกเลิกระหว่างทาง ระบบจะยกเลิกคำสั่งและคืนเงิน
{% endstep %}
{% step %}
### ยืนยันรับของและให้คะแนนคนขับ
เมื่อของถึงที่หมาย ผู้ส่งยืนยันการรับของ ให้คะแนนคนขับ แล้วจบการทำงาน
{% endstep %}
{% endstepper %}

{% hint style="info" %}
**ศูนย์ช่วยเหลือ 🛟** ขั้นที่มีป้าย 🛟 ในภาพ ถ้าพบปัญหาสามารถติดต่อ AI Chat ได้ทันที ถ้า AI แก้ได้จะกลับเข้าสู่ขั้นตอนเดิม ถ้าแก้ไม่ได้จะส่งต่อให้เจ้าหน้าที่ Admin ถ้าปัญหาคลี่คลายจะกลับเข้าสู่ขั้นตอนเดิม ถ้าไม่คลี่คลาย ระบบจะยกเลิกคำสั่งและคืนเงิน
{% endhint %}
{% endtab %}

{% tab title="Driver" %}
<figure><img src="../.gitbook/assets/userflow-driver.jpg" alt="User Flow ของผู้ขับ (Driver)"><figcaption><p>User Flow ของผู้ขับ (Driver)</p></figcaption></figure>

ผู้ขับเปิดระบบรับงาน แล้วทำตามขั้นตอนตามเลขในภาพ

{% stepper %}
{% step %}
### รับแจ้งเตือนงาน
ระบบแจ้งเตือนงานที่เหมาะสมกับรถของผู้ขับ ถ้าไม่รับงาน จะกลับไปรอรับงานใหม่
{% endstep %}
{% step %}
### กดรับงาน
ยืนยันรับงานที่ต้องการ
{% endstep %}
{% step %}
### นำทางไปรับพัสดุ
แอปนำทางไปยังจุดรับพัสดุ
{% endstep %}
{% step %}
### ติดต่อผู้ส่ง
คุยกับผู้ส่งผ่านข้อความหรือการโทร
{% endstep %}
{% step %}
### ถ่ายรูปยืนยันสภาพพัสดุก่อนส่ง
ถ้าเกิดปัญหาระหว่างรับพัสดุ ให้รายงานเหตุขัดข้องทางการขนส่งและติดต่อฝ่ายสนับสนุน
{% endstep %}
{% step %}
### เดินทางไปยังจุดหมาย
นำพัสดุไปส่งยังปลายทาง
{% endstep %}
{% step %}
### ติดต่อผู้รับพัสดุ
คุยกับผู้รับผ่านข้อความหรือการโทร ถ้าเกิดปัญหาระหว่างส่งมอบ ให้รายงานเหตุขัดข้องทางการส่งมอบและติดต่อฝ่ายสนับสนุน
{% endstep %}
{% step %}
### ยืนยันการส่งมอบ
ลูกค้าเซ็นรับหรือถ่ายรูปยืนยันการส่งมอบ
{% endstep %}
{% step %}
### รายงานสถานะพัสดุ
ปิดงาน แล้วผู้ขับได้รับค่าตอบแทน จากนั้นกลับไปรับงานถัดไป
{% endstep %}
{% endstepper %}
{% endtab %}

{% stepper %}
{% step %}
### เข้าสู่ Dashboard
ดูภาพรวมของระบบ
{% endstep %}
{% step %}
### ดูสถานะการจัดส่งทั้งหมด
ติดตามออเดอร์ทุกรายการ
{% endstep %}
{% step %}
### ตรวจสอบประวัติข้อความ
ดูแชทระหว่างคนขับกับผู้ส่งพัสดุ/ผู้รับพัสดุของแต่ละออเดอร์
{% endstep %}
{% step %}
### ตอบกลับข้อความแจ้งปัญหา
ตอบเคสของผู้ใช้งานที่ถูกส่งต่อมาจาก AI Chatbot
{% endstep %}
{% step %}
### ตรวจสอบข้อมูลผู้ขับขี่ (KYC)
ตรวจเอกสารยืนยันตัวตนของผู้ขับ
{% endstep %}
{% step %}
### จัดการข้อร้องเรียนหรือเคสที่มีปัญหา
ดูแลเคสจนเสร็จสิ้น
{% endstep %}
{% endstepper %}
