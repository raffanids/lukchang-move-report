# Driver

แอปผู้ขับครอบคลุมการสมัครและยืนยันตัวตน รับงาน ส่งของ และติดตามรายได้

{% tabs %}
{% tab title="สมัครและยืนยันตัวตน (KYC)" %}
<figure><img src="../.gitbook/assets/driver-intro.jpg" alt="หน้าแนะนำแอปสำหรับผู้ขับ (Progress 2)"><figcaption><p>หน้าแนะนำแอปสำหรับผู้ขับ (Progress 2)</p></figcaption></figure>

หน้าแนะนำ 4 หน้า บอกจุดเด่นของแอป ได้แก่ ระบบจับคู่งานอัจฉริยะ ติดตามแบบ Real-time รายได้โปร่งใส และความปลอดภัย

<figure><img src="../.gitbook/assets/driver-onboarding.jpg" alt="เข้าสู่ระบบและส่งเอกสาร KYC (Progress 2)"><figcaption><p>เข้าสู่ระบบและส่งเอกสาร KYC (Progress 2)</p></figcaption></figure>

ผู้ขับสมัครด้วยเบอร์โทรศัพท์ แล้วอัปโหลดเอกสารยืนยันตัวตน (บัตรประชาชน ใบขับขี่ และทะเบียนรถ) ระหว่างรอ Admin ตรวจ แอปจะแสดงสถานะ "รอตรวจสอบ" และรับงานได้หลังผ่าน KYC เท่านั้น
{% endtab %}

{% tab title="รับงานและระหว่างส่ง" %}
<figure><img src="../.gitbook/assets/driver-jobs.jpg" alt="รับงาน ดูงานที่กำลังจะส่ง แชทกับ Sender และแจ้งปัญหา"><figcaption><p>รับงาน ดูงานที่กำลังจะส่ง แชทกับ Sender และแจ้งปัญหา</p></figcaption></figure>

* **รับงาน:** ดูรายการงานที่เข้ามาพร้อมข้อมูลพัสดุ แล้วกดรับงาน
* **งานที่กำลังจะส่ง:** ดูรายละเอียดจุดรับ จุดส่ง และพัสดุ
* **แชทกับ Sender:** สื่อสารกับผู้ส่งได้ในแอป
* **แจ้งปัญหา:** ถ้าเจอปัญหาระหว่างทาง กดแจ้งได้ทันที
{% endtab %}

{% tab title="ส่งมอบและรายได้" %}
<figure><img src="../.gitbook/assets/driver-delivery.jpg" alt="ส่งของถึงที่หมาย เซ็นชื่อรับพัสดุ ประวัติงาน สรุปรายได้ และโปรไฟล์"><figcaption><p>ส่งของถึงที่หมาย เซ็นชื่อรับพัสดุ ประวัติงาน สรุปรายได้ และโปรไฟล์</p></figcaption></figure>

* **ส่งของจนถึงที่หมาย:** นำทางไปยังปลายทาง
* **เซ็นชื่อเพื่อรับพัสดุ:** ผู้รับเซ็นชื่อยืนยันในแอป เป็นหลักฐานการส่งมอบ
* **ประวัติงาน, สรุปรายได้ และโปรไฟล์:** ผู้ขับดูงานย้อนหลังและรายได้ของตัวเองได้
{% endtab %}
